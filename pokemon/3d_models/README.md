# 3D Models

This folder contains 3D model files for Pokémon.

## Structure
- `models/` - 3D model files organized by region and Pokédex number
- `textures/` - Texture files for models
- `animations/` - Animation files

3D models will be organized with filenames following the format: `XXXX_pokemon_name.format`
where XXXX is the zero-padded Pokédex number (e.g., 0001_bulbasaur.fbx)
